# Privacy Policy — Sincerely Yours

_Last updated: 22 November 2026_

"Sincerely Yours" is a private publishing tool used only by the owner of the Facebook Page "Sincerely Yours" to schedule posts to that Page.

**What data the app accesses.** The app uses the Facebook Graph API with a Page access token to create posts on the Page and to read aggregate statistics for those posts (reach, reactions, comment counts and share counts).

**What data the app does not collect.** The app does not offer Facebook Login to the public, and does not collect, store or process personal data of Facebook users or Page visitors. It does not read the content of comments or messages, and it does not sell or share any data.

**Storage.** Post text and aggregate post statistics are stored privately by the Page owner, only to plan future content.

**Contact.** For any question about this policy, message the "Sincerely Yours" Facebook Page.
